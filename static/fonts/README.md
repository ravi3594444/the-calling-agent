The five WOFF2 files are Latin subsets of weights 400, 500, 600, 700 and 800,
downloaded from the Google Fonts Manrope v20 distribution. Punctuation, the
rupee/euro symbols, and interface arrows are included. Other scripts fall back
to the system font.

Sources: [Manrope](https://github.com/sharanda/manrope),
[Google Fonts source and license](https://github.com/google/fonts/tree/main/ofl/manrope).

Subsetting used fontTools 4.65.0 with WOFF2 output. Fonts are served locally, so
the application makes no third-party font requests.
