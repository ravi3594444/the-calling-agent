When a restaurant is busy, the phone competes with the people in the room. Tableline gives callers a voice host that can answer questions and take reservations.

Choose your demo mode

Live conversation connects your microphone to AssemblyAI through this server. The provider processes audio and may retain session recordings and transcripts.

Interactive demo is a scripted walkthrough with simulated actions. It never opens your microphone, contacts the voice API, or creates a reservation.

This prototype runs browser calls; it is not connected to a telephone number. This build uses an in-memory reservation store. Live bookings last only for the server process and are not shared between instances.

A MEASUREMENT, NOT A PROMISE

What “reply wait” means.

Measured in your browser from receiving the speech-stopped event to scheduling the first reply audio for playback. It includes the playback cushion, but excludes speech detection before that event and device output latency.

The number is the latest measured reply, not a full end-to-end benchmark. Interactive demo timing is never reported as live latency.
